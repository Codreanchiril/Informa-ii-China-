China — Prezentare generală

China, oficial Republica Populară Chineză, este cel mai populat stat din lume, cu peste 1,4 miliarde de locuitori. Este a treia țară ca suprafață și una dintre cele mai vechi civilizații, cu o istorie înregistrată de peste 3.500 de ani.

Capitala Chinei este Beijing (Peking), iar cel mai mare oraș este Shanghai. China are una dintre cele mai rapide economii în creștere din lume și este o putere majoră în afacerile globale.
